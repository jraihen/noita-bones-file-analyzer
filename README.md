# Noita Wand Analyzer

A simple desktop app to parse Noita `.bone` and `.xml` files. It shows wand stats and the spell layout.

## Features

* Reads wand stats like cast delay, recharge time, mana, and capacity.
* Displays wand and spell images.
* Separates and shows "Always Cast" spells.
* Double-click a file in the list to open it in a text editor, or delete files directly from the UI.
* Remembers your last folder and sorts files by modified time.

## Misc

* The code was mostly written with the help of AI(Google Gemini).
