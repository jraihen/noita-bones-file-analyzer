# Noita Wand Bones File Analyzer

Noita Wand Bones File Analyzer is a lightweight desktop GUI application built with Python and Tkinter. It is designed to parse and visualize `.xml` and `.bone` files generated by the game Noita, providing a detailed breakdown of wand statistics and their equipped spells.

## Features

* **Wand Data Parsing:** Automatically reads and extracts key stats from wand data files, including Cast Delay, Recharge Time, Mana, Spread, and Capacity.
* **Visual Representation:** Renders the wand sprite and equipped spell icons in their respective slots using game assets.
* **Always Cast Detection:** Accurately separates and displays permanently attached "Always Cast" spells.
* **File Management:** Browse, load, open, and permanently delete bone files directly from the application interface.
* **Auto-Refresh & Directory Tracking:** Remembers the last used directory and automatically loads files sorted by modification time.

## Requirements

* Python 3.x
* Pillow (PIL)

Install the required dependency using pip:

pip install Pillow

## Setup and Usage

1.  Clone the repository to your local machine.
2.  Ensure you have the required `data` directory containing the game's extracted visual assets (sprites for wands and spells) placed in the root folder of the application.
3.  Run the application:

python main.py

4.  Click **Select Bone Files** to navigate to your Noita save or bone files directory.
5.  Select a file from the list on the left to view its statistics and spell layout.
6.  Double-click a file in the list to open the raw XML/Bone file in your system's default text editor.

## Building an Executable

This project is structured to be compatible with PyInstaller. The `get_resource_path` function ensures that bundled assets (like the `data` folder) are correctly located when running as a compiled executable.

pyinstaller --noconsole --add-data "data:data" main.py
